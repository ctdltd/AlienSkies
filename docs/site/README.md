# Product web page

`alien-skies-embed.html` is the Alien Skies product page for
https://www.certificationtoolanddie.com/products/alien-skies.
The site runs on Google Sites, so the page is pasted in as an HTML embed
(Insert > Embed > Embed code). Its images load from `docs/site/img/` on the
`main` branch through raw.githubusercontent.com, and the trailer from
`video/alien-skies-trailer.mp4`, so keep those paths stable.

When a new release ships, update the version number and download links in
the embed (search for `v26331.0830`).
